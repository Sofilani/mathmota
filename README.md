# 🤖 MathMota | Robô Educacional Interativo

### Tecnologia e inovação aplicadas à educação

O **MathMota** é um robô educacional desenvolvido com o objetivo de tornar o aprendizado da matemática mais dinâmico, interativo e acessível.

O projeto combina conhecimentos de eletrônica, programação e sistemas embarcados para proporcionar uma experiência educativa que une tecnologia e aprendizagem.

## 🎯 Sobre o projeto

Desenvolvido para a **PROJETE 2025**, feira de projetos da ETE FMC, o MathMota propõe uma abordagem interativa para o ensino da matemática.

Por meio da integração entre recursos físicos e digitais, o sistema estimula a participação dos estudantes, oferece respostas às suas interações e permite acompanhar seu desempenho durante as atividades.

## ⚙️ Principais funcionalidades

- Atividades matemáticas interativas.
- Integração entre hardware e software.
- Respostas visuais e físicas às interações.
- Sistema de incentivo e recompensas.
- Registro e acompanhamento do desempenho dos participantes.

## 💻 Tecnologias utilizadas

- Arduino
- Python
- HTML, CSS e JavaScript
- Flask
- SQLite
- Comunicação
